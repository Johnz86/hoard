# Performance evidence

[Catalog measurements](catalog-measurements.md) records historical workloads, measured commits
and results. The [evidence archive](evidence/memory-2026-09-08.tar.gz) preserves the source,
commands and raw results for its dated memory experiment.

These reports are evidence, not current capacity guarantees or an open-work list. Compare
matched builds on the same fixture and hardware before drawing a new conclusion. The
[benchmark task](../../tasks/benchmark-catalog/README.md) describes the current entry points
and the serial measurement protocol.
